## things I'd point you to

Not the whole GitHub — just the ones worth your time.

**[mgt-semantic-kernel](https://github.com/sahil-makandar/mgt-semantic-kernel)**
Document automation where a single OCR pass isn't enough to trust. A chain of agents extracts, cross-checks, and reformats before anything is called "done."

**[ClinicalSetu-AI](https://github.com/sahil-makandar/ClinicalSetu-AI)**
Clinical intent, captured once, turned into the four or five different documents a care pathway actually needs — summaries, referrals, structured notes.

**[SeBrealth-RASA-Agent](https://github.com/sahil-makandar/SeBrealth-RASA-Agent)**
A healthcare assistant on RASA CALM. The hard part was never the happy path — it was every way a patient phrases the same question.

**[mcp-servers-github-mslearn-filesystem](https://github.com/sahil-makandar/mcp-servers-github-mslearn-filesystem)**
Three MCP servers so an agent can read GitHub, search Microsoft Learn, and touch the filesystem — the unglamorous plumbing that makes "agentic" mean something.
